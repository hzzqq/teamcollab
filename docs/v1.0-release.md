## 1. 项目定位与边界

**一句话**：一个团队协作 SaaS 的 MVP——把"任务拆解 / 状态流转 / 围绕任务的沟通 / 通知 / 权限"收敛到一个产品里，替代微信刷屏式协作。

**边界宪法（`PROJECT_BOUNDARY.md`，2026-08-07 划死，v1.0 严守）**：

- ✅ **只做一件事**：一个协作 SaaS 产品（看板 / 任务 / 评论 / 通知 / RBAC / 多租户）。
- ❌ **明确不做（锁死）**：应用市场 / 插件 / 低代码 / 流程引擎 / 通用 BI；文档协作 / IM / 日程 / 文件存储。这些与 project2、project3 等同类项目重复造轮子，或属重资产，v1.0 一律不碰。
- ❌ **视觉红线（P0 门禁）**：禁止紫粉渐变；图标仅用 `lucide-react`（全项目唯一）；代码零 emoji（文案/UI 可正常中文）。

**演示账号**：`pm@example.com` / `pass1234`（团队"Demo 产品团队"，含示例看板与任务）。

## 5. 关键架构决策与历史坑（诚实记录）

| 项 | 决策 / 坑 | 处理方式 |
|----|-----------|----------|
| 跨列拖拽 real 模式必 400 | 前端曾传"源列"进 URL 路径，后端按"目标列"校验 | 抽出 `lib/drag-position.ts` 为前后端唯一真相源；路径≠body 目标列 → 400 不静默接受 |
| 列删除静默丢任务 | `tasks.column_id` 是 `ON DELETE CASCADE`，直接删列会连删任务 | **非空列 409 拦截**，引导先清空/移动任务；删看板才级联（确认后整体销毁） |
| SSE 实时通知从未生效 | `EventSource` 只收匿名 `onmessage`，服务端发的是命名事件 `event: notification` | 改用 `addEventListener("notification")` |
| 到期提醒时区漏发 | 窗口用 UTC 取 `.date()`，UTC+8 下少算一天 | 改按本地时区计算 |
| 通知长连接独占 DB 连接 | SSE 流依赖链带 `get_db`，长连接期间连接池被占 | 去掉 `get_db` 依赖，长连接期间 `pool.checkedout() == 0` |
| 单条通知已读（v1.0 新增） | 此前仅有"全部已读"，点击通知不标记已读 | `POST /notifications/{id}/read`，限定属主，跨用户 40401 不泄露存在性；前端乐观更新 |

## 6. 已知限制

1. **大看板虚拟滚动：暂未实施**。Spec §9 仅在 >1000 任务/看板时触发；当前数据量远低于阈值，且 dnd-kit 与虚拟列表集成脆弱、易回归拖拽契约。属"无真实数据验证的投机代码"，故延后——待数据量真实逼近阈值时，按 `@tanstack/react-virtual` + 活跃拖拽项保序方案落地。
2. **【2026-11-06 勘误】本分内功能 ≠ 边界禁区**：v1.0 初稿把「任务多层级 / 依赖 / 列表视图 / 活动流 / 全局搜索 / 附件」写成「`PROJECT_BOUNDARY.md` 明确不做、须先修订宪法」，**这是文档错误**。核对宪法拒绝清单原文（第 30–38 行）只禁：文档协同编辑、即时通讯/群聊、日历/日程、文件网盘/对象存储、通用 BI/报表、低代码/流程引擎/应用搭建器、把鉴权/存储拆成独立 SaaS。**列表视图 / 活动流 / 全局搜索 / 任务子层级 / 批量操作 / 视图切换均属看板协作本分，可直接开工，无需修订宪法**；仅「附件（需对象存储）」与「跨项目仪表盘（偏通用 BI）」仍受边界约束。
3. **本机 `next build`：已解决（2026-11-06）**：裸跑会被宿主 safe-delete 门禁拦 Next 内部 unlink；读 `node-safe-delete-shim.cjs` 源码确认 `CODEBUDDY_SAFE_DELETE_ENABLED=0` 是官方总开关（第 24 行直接 return），加该变量后本机构建实测成功。旧稿「本机无法跑 next build」及「须靠 CI 替代」的结论作废。⚠️ 新建 git worktree 目录内仍可能因沙箱 `EPERM .next/trace` 失败，构建请在主区执行。

## 7. 部署形态

| 场景 | 方式 |
|------|------|
| 本地开发 | `python start_dev.py`（自动检测/拉起自带 PostgreSQL + alembic 迁移 + 后端）；`npm run dev`（前端 rewrite `/api/*` → `:8000`） |
| 一键验证 | `start_dev.py --db-only`（准备库与迁移）；端到端冒烟脚本（需后端在 :8000） |
| 生产（全栈） | `docker-compose.prod.yml`：nginx(:80) → web + api×2 + pg + redis，开箱即用 |
| 多实例运行时 | 配置 `REDIS_URL` 一键切换：SSE 广播 / 限流共享计数 / 调度器互斥 全部走 Redis；默认仍走进程内内存实现 |

**生产配置自检**：`JWT_SECRET` 去掉默认值兜底；`ENVIRONMENT=production` 时启动自检弱密钥/过短直接拒绝启动。

## 8. 后续路线（2026-11-06 按边界复核重分类）

> v1.0 初稿误把本分内功能升级成「宪法禁止」，本节已勘误。判断依据一律以 `PROJECT_BOUNDARY.md` 第 30–38 行拒绝清单原文为准。
